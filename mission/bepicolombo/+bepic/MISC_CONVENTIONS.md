

# Dictionary

AR : Non-cell MATLAB array.

Constant-length time windows : Spin fitting time windows which beginning and end are determined by time, e.g. begin and end at "t mod t_0 = 0".

RAD : Radians

Spin-aligned time windows : Spin fitting time windows which beginning and end are determined by the spin phase, e.g. begin and end at spin phase=0.

TT2000 : CDF time format "TT2000".
