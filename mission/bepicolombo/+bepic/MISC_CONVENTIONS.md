
# Dictionary

Abbreviations used in this code.

ACT : Actual. Refers to an "actual value" generated by the tested code in a unit
test.

AR : Non-cell MATLAB array.

CSP, Cumulative Spin Phase : Spin phase (angle) which counts the total
(estimated) angle of rotation, i.e. which (1) always increments with time, and
(2) is *NOT* constrained to always be between e.g. 0 to 2*pi.

EXP : Expected. Refers to an "expected value" which is compared with an "actual
value" generated by the tested code in a unit test.

Fit Window : A period of time over which data is fitted to a function (a "spin fit").

RAD : Radians

SAFW : Spin-Aligned Fit Window. Spin fitting time window which beginning and end are determined by spin phase, e.g. begin and end at spin phase=0 (mod 2*pi).

TAFW : Time-Aligned Fit Window. Spin fitting time window which beginning and end are determined by time, e.g. the beginning and end are at t_0+n*delta and t_1+n*delta.

TT2000 : CDF time format "TT2000". Nanoseconds since epoch, including leap seconds.
