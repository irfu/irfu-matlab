
# Dictionary

Abbreviations used in this code.

ACT : Actual. Refers to an "actual value" generated by the tested code in a unit
test.

AR : Non-cell MATLAB array.

Constant-length time window : Spin fitting time window which beginning and end are determined by time, e.g. begin and end at "t mod t_0 = 0".

Cumulative spin phase : Spin phase (angle) which counts the total angle of rotation, i.e. which (1) always increments with time, and which (2) is *NOT* constrained to always be between e.g. 0 to 2*pi.

EXP : Expected. Refers to an "expected value" which is compared with an "actual
value" generated by the tested code in a unit test.

RAD : Radians

Spin-aligned time window : Spin fitting time window which beginning and end are determined by the spin phase, e.g. begin and end at spin phase=0.

TT2000 : CDF time format "TT2000". Nanoseconds since epoch, including leap seconds.
