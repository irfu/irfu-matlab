Directory for the BepiColombo mission, including both
(a) Mio (Mercury Magnetospheric Orbiter, MMO; JAXA) and
(b) the Mercury Planetary Orbiter (MPO; ESA).
IRF's MEFISTO instrument is part of Mio.


Required MATLAB Toolboxes
=========================
The code requires MATLAB's Optimization Toolbox (optimoptions, lsqcurvefit).
It can not be excluded that further toolboxes are required too.
